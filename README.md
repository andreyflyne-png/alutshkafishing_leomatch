# Рыбалка: Telegram-бот на Claude

Приложение, которое общается в Telegram от лица владельца аккаунта с помощью модели Claude (Anthropic API). Работает в окне Chromium (Playwright) с Telegram Web, вход по QR-коду, управляется из консоли.

Бот для приложения знакомств Leomatch: смотрит анкеты, лайкает подходящие по описанию стиля (`style.md`), пишет первым после взаимной симпатии и ведёт переписку по легенде (`persona.md`).

## Что умеет

- Оценка анкет по скриншоту: возраст проверяет код (младше 18 или не указан возраст: анкета пропускается), стиль и телосложение оценивает модель по `style.md`. Обучающие примеры («лайкать» / «не лайкать») подкладываются из `data/examples`.
- Приоритет переписки: если кто-то написал, лайки замирают и бот отвечает.
- Переписка похожа на человеческую: разные формы ответа (реакция, вопрос, несколько коротких сообщений), темп набора, память о собеседнице (факты, уже заданные вопросы), смена застрявшей темы, активное начало диалога, уровень флирта зависит от её интереса.
- Защита: эскалация (останавливается и зовёт владельца), если собеседник всерьёз спрашивает «ты бот?», пишет о самоповреждении или говорит, что ему нет 18; не соглашается на встречи, не даёт контактов и денег.
- Режимы `--gui` / `--demo` для внешнего приложения-панели (панель в репозиторий не входит).

## Быстрый старт

Нужны Python 3.10+ и ключ Anthropic API (console.anthropic.com).

```bash
cd rybalka
./setup.sh            # окружение, библиотеки, Chromium (один раз)
cp .env.example .env  # и впиши в .env свой ANTHROPIC_API_KEY
./run.sh              # при первом запуске отсканируй QR (Настройки → Устройства)
```

Подробности в `rybalka/README.md`. Опционально подключи команду `rybalka run`: `source rybalka/rybalka.zsh`.

Тесты: `.venv/bin/python -m unittest discover -s tests` внутри папки `rybalka`.

## Что нужно заменить под себя

- `rybalka/persona.md` — легенда и манера общения; `rybalka/style.md` — кого лайкать.
- `rybalka/config.json` — темп, лимиты, список чатов для автоответов (`chat_usernames`, по умолчанию пуст).

## Важно

- Ключ API и сессия Telegram хранятся только локально (`.env`, `data/` в `.gitignore`). Никогда не публикуй их и экспорты своих переписок.
- Это автоматизация личного аккаунта. Используй её на своём аккаунте, соблюдай правила Telegram и сервисов знакомств (в том числе правила об автоматизации и о выдаче бота за человека), не спамь и не обманывай людей в серьёзных вещах: деньги, встречи, личные данные. Бот специально останавливается в таких ситуациях, но ответственность за использование на тебе.
- Лимит на ресурс: каждый ответ и каждая оценка анкеты это платный запрос к API.
